🎓 Java Student Records

A simple Java student records management system that demonstrates File Handling, data storage, searching, and basic Object-Oriented Programming concepts.

The program allows users to add student records, view saved students, and search for a student by ID.

✨ Features

- Add new student records
- Save student data to a text file
- View all saved students
- Search for a student by ID
- Handle missing files
- Simple interactive console menu

🧠 Concepts Demonstrated

- File Handling
- FileWriter
- File reading using Scanner
- Exception Handling
- Methods
- Loops
- Conditional statements
- Switch statement
- String handling

🛠️ Technologies

- Java
- File I/O
- Scanner
- FileWriter
- Exception Handling

📁 Data Storage

Student records are stored in:

students.txt

Each record contains:

Student ID | Student Name | Major

▶️ How to Run

Make sure Java is installed on your computer.

Compile the program:

javac StudentRecords.java

Run the program:

java StudentRecords

🎮 Available Operations

1. Add Student
2. View Students
3. Search Student
4. Exit
